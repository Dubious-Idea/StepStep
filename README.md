## Что это

Шагомер, который считает калории честно — не «шаги × коэффициент», а по
уравнению ходьбы ACSM. Рост задаёт длину шага, длина шага и количество шагов
дают дистанцию, дистанция и время в движении дают скорость, а скорость и вес
дают расход энергии. Поэтому 10 000 шагов быстрым шагом стоят дороже, чем те
же 10 000, размазанные по всему дню.

Шаги видны в трёх местах: в приложении, в постоянном уведомлении на экране
блокировки и в виджете 4×2 на рабочем столе.

## Экран блокировки

Виджетов на экране блокировки в Android на телефонах **нет** — их убрали в
Android 5, а в Android 15 вернули только для планшетов. Поэтому шаги на
локскрине показывает постоянное уведомление с тем же неоновым кольцом. Его
можно выключить в профиле.

## Как устроено

Датчик, хранилище и формула калорий живут в Kotlin, а не в Dart. Причина
простая: виджет и уведомление должны рисоваться, когда Flutter-движок не
запущен. Flutter не держит вторую копию данных, а спрашивает снапшот через
`MethodChannel` — так три поверхности не могут разойтись в цифрах.

```
lib/
├── models/          профиль и дневная статистика
├── services/        метрики, мост к нативу, разрешения, обновления
├── screens/         онбординг, главный, профиль
├── theme/           токены тёмного люкса
└── widgets/         кольцо, бенто-карточки, график недели

android/app/src/main/kotlin/com/purrweb/stepstep/
├── StepRepository       единственный источник правды по шагам
├── StepService          foreground-сервис, уведомление на локскрине
├── StepWidgetProvider   виджет рабочего стола
├── RingRenderer         кольцо на Canvas для уведомления и виджета
├── Metrics              зеркало lib/services/metrics.dart
└── PermissionCoordinator
```

**Формула калорий продублирована** в `lib/services/metrics.dart` и `Metrics.kt`
— менять нужно в обоих местах. Эталонное значение зафиксировано в
`test/metrics_test.dart`: 10 000 шагов / 175 см / 75 кг / 100 активных минут
≈ 271,7 ккал.

## Зависимости

Их нет. Ни шагомерных пакетов, ни `permission_handler` — всё, что им нужно
делать, уже есть в нативном слое, который необходим для виджета.

## Сборка

```bash
flutter pub get
flutter run                       # debug на подключённом устройстве
flutter build apk --release       # релизный APK
```

Требуется Flutter 3.44+, Android 8.0+ (minSdk 26) и аппаратный датчик шагов.

## Тесты

```bash
flutter test --exclude-tags golden          # то же, что гоняет CI
flutter test --update-goldens test/golden   # перезаписать пиксельные снимки
```

Голдены исключены из CI: они сравнивают пиксели, записанные на машине
разработчика, а Linux-раннеры рендерят текст иначе.

## Релизы и обновления

Тег `v*` собирает подписанный APK и публикует релиз. Приложение при запуске
проверяет GitHub Releases и предлагает скачать новую версию — магазина нет,
так что это единственный канал доставки.

```bash
# поднять версию в pubspec.yaml, описать изменения в RELEASE_NOTES.md
git tag v1.0.1 && git push --tags
```

Для подписи нужны секреты репозитория: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_PASSWORD`, `KEY_ALIAS`. Без них сборка проходит, но APK подписан
отладочным ключом и не встанет поверх подписанного релиза.

## Иконка

Генерируется, а не рисуется руками:

```bash
python3 tool/generate_icon.py
```

Скрипт рендерит матовый low-poly объект с фирменным кольцом и раскладывает его
по всем плотностям, включая adaptive- и monochrome-слои.
